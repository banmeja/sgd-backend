# Proyecto SGD

Base y esquema de proyecto sgd

## 🚀 Tecnologías
- Angular 17 (Frontend) + Node.js 20 
- Java 21 + Spring Boot 3 (Backend) + Maven
- Oracle 19c (Base de datos)

## ⚙️ Arquitectura
- El frontend (Angular) consume APIs de Node y Spring Boot.
- Java maneja autenticación y servicios auxiliares.
- Spring Boot maneja lógica principal y conexión a Oracle.
- Oracle almacena datos
